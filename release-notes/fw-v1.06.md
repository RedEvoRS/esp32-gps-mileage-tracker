Firmware **v1.06** for the LilyGO **T-Beam Supreme** with the u-blox **MAX-M10S** GPS (not the L76K version): repairs a trip file with a torn end in place, cutting it after the last complete point and adding the closing tags instead of copying the whole trip, so even a large damaged trip can be repaired on the 2.375 MB internal flash. Finishing a trip no longer blocks GPS reading during a long scan. Server **v1.07** ships in the same release: an Admin setting for how many days of diagnostics events to keep (365 by default, from 30 to 3650 days), with old events deleted after diagnostics uploads, and nightly backups that re-check older snapshots on a rotation (weekly by default, three snapshots, always including the oldest, both local and off-host) and fail the backup run if one is damaged.

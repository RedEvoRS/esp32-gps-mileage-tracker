Firmware **v1.09** for the LilyGO **T-Beam Supreme** with the u-blox **MAX-M10S** GPS (not the L76K version) fixes six diagnostic-journal bugs found in a code audit. Journal startup now lists `/diag` in a single pass and keeps its place when interrupted by GPS writes, so weeks of stored diagnostic segments no longer stall microSD loading, and space cleanup now evicts the oldest sealed segment at the 512-segment limit as well as the byte cap. Dropped-event accounting no longer underflows after a cancelled metadata read-back, one-time snapshot enrollment preloads mounted journals cooperatively before protecting its bounded metadata commit from trip storage traffic and only consumes its enrollment ID after a journal save succeeds, and power-off now seals open segments promptly on a full RAM queue while bounding retries of failed journal writes to three consecutive stalled attempts inside the existing 15-second shutdown window. These changes have host tests only; bench and road checks remain to be done.

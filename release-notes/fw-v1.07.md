Firmware **v1.07** for the LilyGO **T-Beam Supreme** with the u-blox **MAX-M10S** GPS (not the L76K version): prevents runtime USB serial output from waiting for a PC that stops reading, and keeps the once-a-minute GPS clock correction quiet unless debug mode is on. A larger GPS receive buffer provides more margin, and track segments use GPS time when available so delayed processing alone does not split continuous coverage. Debug mode reports long GPS-reading pauses, with a count and maximum on the live page. Bench comparison with v1.06 and a road drive remain to be checked.

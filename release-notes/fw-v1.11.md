Firmware **v1.11** for the LilyGO **T-Beam Supreme** with the u-blox **MAX-M10S** GPS uses the board-air temperature to help decide when to pause charging. This helps it pause in a cold car even when charging has warmed the power chip. Charging resumes when all available readings return to range. The debug temperature line shows the same readings the guard used and drops the unused TS voltage. No server update is needed.

Firmware **v1.11** for the LilyGO **T-Beam Supreme** with the u-blox **MAX-M10S** GPS (not the L76K version) fixes four power, charging and storage-mode bugs. Power-chip interrupts now clear only the flags read in the current batch using checked writes before starting shutdown preparation, remember already-handled bits on a failed clear so retries clear them without replaying actions, retry failed startup IRQ enables and failed clears or an asserted IRQ line every 100 ms, and periodically recheck USB power every 15 s so a missed interrupt cannot leave power state stale. At startup, the early charger disable is verified by read-back and retried for a bounded 5 s window before storage setup; if the power chip still cannot confirm charging off, firmware cannot guarantee the charger stays off during storage startup, raises E2008 (`Charge control fail`) and continues rather than blocking trip logging forever, and the charge guard requires a verified 4.1 V charge target before enabling charging (also raising E2008 if unconfirmed). Unreadable or implausible charge-temperature samples still pause charging fail-safe without creating hot/cold hysteresis history or false E2004/E2005 alerts. Boot storage selection now uses one authoritative startup capacity query, leaves a capacity-failed microSD card mounted with `gSdUnavailable` latched (avoiding an immediate power cut without settle), enters no-storage mode and reports E4003 (`No recording storage available`) when internal flash is also unavailable, requires the card capacity check to succeed before a degraded no-storage retry restarts, and reports E4003 when the selected trip store fails at runtime with no fallback. No server update is required for these changes, which have host tests only; bench and road checks remain to be done.

Firmware **v1.11** for the LilyGO **T-Beam Supreme** with the u-blox **MAX-M10S** GPS uses the board-air temperature to help decide when to pause charging. This helps it pause in a cold car even when charging has warmed the power chip. Charging resumes when all available readings return to range. The debug temperature line shows the same readings the guard used and drops the unused TS voltage. A first install now gives the internal flash about 15 hours of backup trip storage for when the microSD card can't be used, up from about 5–6 hours. A normal update keeps the old size. To get the larger store on a tracker you already use, upload or back up any trips on internal flash first, then do a first install, which erases internal flash, and re-enroll diagnostics afterwards. The PC flash helpers also check more strictly where each firmware part goes before writing it. If the startup power-chip check (E2010) finds a problem, the running tracker now keeps reporting it, so Device health and alerts still show it if the first report was missed. No server update is needed.

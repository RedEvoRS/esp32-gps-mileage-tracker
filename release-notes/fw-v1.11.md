Firmware **v1.11** for the LilyGO **T-Beam Supreme** with the u-blox **MAX-M10S** GPS (not the L76K version) fixes four power, charging and storage-mode bugs. Power-chip interrupts now clear only the flags read in the current batch using checked writes before starting shutdown preparation, retry on failed clears or an asserted IRQ line, and periodically recheck USB power so a missed interrupt cannot leave power state stale. At startup, the early charger disable is verified by read-back with retries before storage setup, and the charge guard now requires a verified 4.1 V charge target before enabling charging, raising E2008 (`Charge control fail`) if the target cannot be confirmed. Unreadable or implausible charge-temperature samples still pause charging fail-safe without creating hot/cold hysteresis history or false E2004/E2005 alerts. If the microSD card fails its boot-time capacity check when internal flash is unavailable, the tracker now enters no-storage mode and reports E4003 (`No recording storage available`) instead of staying in normal mode, and runtime failure of the selected trip store with no fallback also reports E4003. No server update is required for these changes, which have host tests only; bench and road checks remain to be done.
